# Переработка SC NEXUS

Приоритет пользователя: торговля, флот и инструменты ПК. Ориентир по составу возможностей — [SC Portal RU](https://sc-portalru.com/), в частности [грузовые маршруты](https://sc-portalru.com/hauling), [каталог кораблей](https://sc-portalru.com/ships), [SC Doctor](https://sc-portalru.com/tools/sc-doctor) и [SC Logbook](https://sc-portalru.com/tools/sc-logbook).

## Что исправлено

| Экран | Проблема | Изменение |
| --- | --- | --- |
| Оболочка | Одинаковые пункты меню, потеря контекста, прокрутка переносилась между страницами | Боковое меню с активным пунктом, постоянный заголовок, сброс прокрутки при переходе |
| Обзор | Мало полезных действий и повторение других страниц | Доступный бюджет, прибыль, текущий рейс, флот и состояние игры с переходами |
| Маршруты | Баланс, резерв и старт приходилось менять в настройках | Параметры рядом с поиском, старт из всех локаций, дополнительные фильтры в раскрываемом блоке |
| Маршруты | Нет явного обновления котировок | Кнопка принудительного обновления, состояние загрузки, время данных |
| Карточки | Сложно оценить заполнение трюма | Полоса заполнения, SCU, системы, Pyro и NQA; подробности можно скрыть |
| Флот | Большая форма постоянно занимала экран | Раскрываемое добавление, обычный список моделей, отдельный поиск, автоматическая роль, сравнение вместимости |
| Рейсы | Незавершённый рейс выглядел как убыток | Статус «В пути», запрет начала второго рейса, защита активного рейса от замены выбранным маршрутом |
| Рейсы | Запросы из Game.log вытесняли историю | Раскрываемый блок запросов, экспорт истории в CSV |
| Инструменты | Только несколько признаков наличия игры | Windows, процессор, память, версия файла игры, диск, журналы, конфигурация, локализация и экспорт отчёта |
| Настройки | Баланс, локация и параметры приложения в одной длинной форме | Отдельные группы подключения, мониторинга, отображения и личных данных |
| Суммы | Нечитаемые числа с точкой и отсутствие проверки | Русские разделители, пробелы между разрядами, проверка отрицательных и некорректных значений |
| Данные | Нет удобного переноса | Резервная копия SQLite, экспорт CSV, открытие папки данных |

## Границы текущего выпуска

SC NEXUS использует собственные экраны и открытые котировки UEX. В приложении работают локальный мониторинг, проверка файлов, журнал сессий и учёт торговых запросов. Полная замена отдельных утилит сайта ещё не реализована: нет установки русификатора, изменения подсветки ресурсов, очистки игровых файлов и панели управления с телефона.

Дальнейшие самостоятельные модули: склад и снаряжение, учёт добычи, грузовые контракты и план остановок. Справочники компонентов, оружия, миссий и новости потребуют отдельных источников данных. Аукцион и сервисы сообщества используют серверную часть сайта и не являются локальными функциями приложения.

## Проверка

Автотесты: числа в русской записи, миграция настроек, резервная копия с флотом и активным рейсом, CSV, расчёт маршрутов и чтение журналов. Визуальная проверка проводится в Windows на запущенной сборке; отдельно проверяются меню, настройки и выбор корабля.
