# SC NEXUS 0.5.8

## Русский

- При обычной установке явно показывается выбор English / Русский.
- При первом запуске приложения появляется двуязычное окно выбора. Предлагается язык установщика, а для portable-версии — русский на русской Windows и английский на остальных системах.
- Выбор сохраняется. Обновление не сбрасывает язык существующего профиля; поменять его можно в настройках.
- Подтверждение и этапы обновления переведены на английский. Проверка GitHub ограничена 30 секундами, чтобы не оставлять кнопку занятой надолго при проблемах сети.
- Проверены сохранение языка, выбор в интерфейсе, загрузка обновления с проверкой SHA-256 и доступ к публичным релизам при отозванном токене.

## English

- The interactive installer explicitly offers English / Русский.
- A bilingual first-launch screen suggests the installer language, or the Windows language for portable users (Russian on Russian Windows, English otherwise).
- Your choice is saved and preserved across updates. Change it later in Settings → Language.
- Update prompts and progress messages now support English. GitHub update checks time out after 30 seconds if the network is unavailable.
- Verified language persistence, the language selector, SHA-256-checked update downloads, and public release access with a revoked saved token.
