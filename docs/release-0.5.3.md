# SC NEXUS 0.5.3

## English

- Added an interactive **Force ship detection** button to the expanded in-game overlay.
- The button runs one local OCR scan without enabling periodic OCR. The rest of the overlay stays click-through for normal game input.
- OCR can now find the visible Star Citizen window when the SC Nexus overlay is the active window.
- Added clear in-app and README instructions for ship recognition using Vehicle Loadout, ASOP, Fleet Manager, retrieval, or HUD screens.
- Added interface screenshots to the English and Russian project pages.
- Added automated coverage for a forced OCR refresh. All 81 tests pass.

## Русский

- В расширенный игровой оверлей добавлена интерактивная кнопка **«Принудительно обнаружить корабль»**.
- Кнопка выполняет один локальный OCR-скан без включения постоянного OCR. Остальная часть оверлея остаётся прозрачной для кликов в игре.
- OCR теперь находит видимое окно Star Citizen, когда активен оверлей SC Nexus.
- В настройки и оба README добавлена понятная инструкция: обнаружение корабля через Vehicle Loadout, ASOP, «Мой флот», экран выдачи или HUD.
- В английскую и русскую страницы проекта добавлены скриншоты интерфейса.
- Добавлен тест принудительного OCR-обновления. Проходят все 81 тест.
