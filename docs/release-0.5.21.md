# SC NEXUS 0.5.21

## English
- Refined the minimal workspace: the dashboard now shows recent trips and live game status without empty placeholder cards.
- Reworked Fleet into a compact table with ship details, sorting, and a collapsed add-ship panel.
- Added optional ship portraits from the Star Citizen Wiki. The app continues to work normally when a picture or network connection is unavailable.
- Improved the overlay with the Nexus balance, data freshness, risk visibility, and missions in expanded mode.
- Completed Russian and English interface checks with 152 automated tests.

## Русский
- Доработан минимальный рабочий интерфейс: в «Обзоре» появились последние рейсы и состояние игры без пустых карточек.
- «Флот» перестроен в компактную таблицу с деталями корабля, сортировкой и свёрнутым добавлением корабля.
- Добавлены необязательные изображения кораблей из Star Citizen Wiki. При отсутствии сети или изображения приложение продолжает работать как обычно.
- Оверлей теперь показывает баланс Nexus, свежесть данных, риск и миссии в расширенном режиме.
- Русский и английский интерфейсы проверены 152 автоматическими тестами.
