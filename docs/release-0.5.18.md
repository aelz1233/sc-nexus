# SC NEXUS 0.5.18

## English
- Added a dedicated Equipment workspace for component comparison, build recommendations, and shopping routes.
- Reworked Fleet into a selectable ship list with focused details and actions.
- Refined shared spacing, section hierarchy, navigation, and light/dark theme presentation.
- Updated the overlay with a concise ship, balance, and active-task header; the checklist expands when needed.
- Added an in-settings overlay preview and kept the existing Russian and English interface support.
- Verified with 152 automated tests.

## Русский

- Флот переделан в список с подробностями и действиями для выбранного корабля.
- Уточнены общие отступы, иерархия разделов, навигация и отображение в светлой и тёмной темах.
- Оверлей получил компактную шапку с кораблём, балансом и текущей задачей; чек-лист раскрывается по необходимости.
- В настройках появился предпросмотр оверлея; сохранена русская и английская локализация.
- Пройдены 152 автоматических теста.
