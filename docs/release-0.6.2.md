# SC NEXUS 0.6.2

## English
- Fixed optional ship portraits for ASOP names that differ from the Star Citizen Wiki, including Ares Ion and Ares Inferno.
- Route results now use only the space they need for short lists and grow into a scrollable list for large route sets.

## Русский
- Исправлена загрузка необязательных изображений для названий ASOP, которые отличаются от Star Citizen Wiki, включая Ares Ion и Ares Inferno.
- Таблица маршрутов занимает высоту по числу строк в коротком списке, а при большом количестве вариантов становится прокручиваемой.
