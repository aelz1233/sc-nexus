# SC NEXUS 0.2.2

- В журнал рейса добавлены автозаполнение сумм из `Game.log`, ручная правка и кнопка обновления.
- Добавлена статистика завершённых рейсов за час, день, три дня, неделю, месяц, полгода или год.
- Завершённый рейс можно удалить из истории с корректировкой баланса.
- Выбор систем маршрута переработан в компактные переключатели; массовый выбор больше не запускает лишние пересчёты.
- Исправлены проблемы интерфейса и проверена сборка приложения.
