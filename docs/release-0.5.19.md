# SC NEXUS 0.5.19

## English
- Redesigned the full application around a calmer flight-operations workspace: shared navigation, header, panels, forms, tables, tabs, and status bar now use one compact visual system.
- Refined the Routes workspace into a clearer commodity-and-route table with investment, profit, and risk. Pyro and NQA risks are shown without inventing unsupported risk levels.
- Simplified the overlay around the next planned action and removed cargo and fuel values that were not confirmed by live data.
- Completed English-mode coverage for the main screens, including route, overlay, tooltip, accessibility, and dynamic journey text.
- Verified with 152 automated tests.

## Русский
- Полностью обновлён интерфейс в стиле операционной консоли: навигация, шапка, панели, поля, таблицы, вкладки и строка состояния теперь используют одну компактную визуальную систему.
- Раздел маршрутов стал понятнее: товар и путь показаны в одной строке, рядом — инвестиции, прибыль и риск. Для Pyro и NQA отображаются только подтверждённые уровни риска.
- Оверлей сфокусирован на следующем действии по плану; убраны значения груза и топлива, которые не подтверждаются живыми данными.
- Доработан английский режим на основных экранах: маршруты, оверлей, подсказки, доступные имена и динамические описания рейсов.
- Пройдены 152 автоматических теста.
