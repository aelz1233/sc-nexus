## SC NEXUS 0.6.9

- В разделе «Маршруты» добавлена вкладка «Фильтры»: безопасность, Pyro/NQA, категория, прибыль, минимальная загрузка, резерв и разрешённые системы.
- Начальная локация теперь выбирается из списка систем, по умолчанию «Все системы».
- Выбор стартовой системы влияет только на торговые маршруты и не перезаписывает локацию персонажа.
- Добавлены тесты для стартовой системы и навигации по вкладкам.
