# SC NEXUS 0.5.1

## English

This release refreshes the entire interface and simplifies route and loadout setup.

- Added a system-only origin option: choose Stanton, Pyro, or another system without selecting a specific terminal.
- Applied the origin system consistently to direct routes, chains, and multi-stop cargo collection.
- Rebuilt the loadout configurator into a compact layout with separate budget and maximum-build tabs.
- Kept shopping routes visible while moving technical details and full component lists into expandable sections.
- Refreshed the dashboard, navigation, headers, cards, buttons, text fields, password fields, selectors, tabs, and expanders with one consistent visual system.
- Extended Russian and English interface text for the new controls.
- Added regression coverage for system-only route origins. All 78 automated tests pass.

## Русский

В этом выпуске полностью обновлён интерфейс и упрощена настройка маршрутов и оснащения.

- Добавлен старт из целой системы: можно выбрать Stanton, Pyro или другую систему без конкретного терминала.
- Ограничение начальной системы одинаково работает для прямых рейсов, цепочек и сбора груза с нескольких остановок.
- Конфигуратор оснащения стал компактнее; сборки за бюджет и без ограничения суммы разделены по вкладкам.
- Маршруты закупки остаются на виду, а технические детали и полный список компонентов убраны в раскрывающиеся блоки.
- Главный экран, навигация, шапки, карточки, кнопки, поля, пароли, списки, вкладки и раскрывающиеся блоки приведены к единому обновлённому стилю.
- Дополнен русский и английский текст новых элементов.
- Добавлены регрессионные тесты старта из системы. Проходят все 78 автоматических тестов.
