# SC NEXUS

Личный Windows-компаньон для торговли и грузовых рейсов в Star Citizen.

## Скачать

Готовая версия для Windows x64 находится в [Releases](https://github.com/aelz1233/sc-nexus/releases).

- `SCNexus-Setup-…exe` — установщик с ярлыком в меню «Пуск»;
- `SCNexus-…win-x64.zip` — переносная версия без установки.

Приложение не требует отдельной установки .NET. Личные данные сохраняются на компьютере в `%LOCALAPPDATA%\\SCNexus` и не удаляются при обновлении.

## Возможности

### Маршруты и торговля

- подбор выгодных рейсов по трюму, балансу, запасу и спросу;
- поиск из конкретной точки или сразу из всех локаций;
- фильтры по системам, Pyro, NQA, заполнению и минимальной прибыли;
- сортировка по прибыли, марже, вложениям и заполнению;
- пометка опасных маршрутов через Pyro;
- режимы «Прямой рейс», «Цепочка» и «Сбор груза»;
- несколько остановок с выбором конечной точки или автоматическим подбором.

### Флот и история

- выбор корабля из каталога UEX с автоматической вместимостью и ролью;
- личный флот, заметки о сборке и сортировка по названию или вместимости;
- журнал рейсов с фактическими вложениями, выручкой, расходами и потерями;
- автозаполнение торговых сумм из `Game.log` с возможностью исправить их вручную;
- статистика завершённых рейсов за час, день, три дня, неделю, месяц, полгода или год;
- удаление ошибочной записи из истории с корректировкой баланса.

### Инструменты ПК

- поиск папки игры и `Game.log`;
- чтение последних запросов покупки и продажи;
- статус запущенной игры, сервера и региона;
- проверка места на диске, `user.cfg` и локальных файлов;
- экспорт истории в CSV и резервная копия личной базы.

## Данные рынка

Котировки, терминалы и каталог кораблей загружаются из [UEX](https://uexcorp.space/). Данные кэшируются локально, поэтому приложение продолжает работать при временной недоступности сети. Перед покупкой груза проверяйте цены и наличие в игре: рынок может измениться до прибытия.

## Сборка из исходников

Требуются Windows и .NET 10 SDK.

```powershell
dotnet run --project SCNexus/SCNexus.csproj
```

```powershell
dotnet test SCNexus.slnx -c Release
```
