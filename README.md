# SC NEXUS

Личное Windows-приложение-компаньон для Star Citizen. Боковое меню объединяет обзор, торговые маршруты, флот, рейсы, инструменты ПК и настройки. Текущий корабль и баланс остаются видны в заголовке.

## Запуск

Готовый **установщик Windows x64** и **ZIP без установки** доступны в [Releases](https://github.com/aelz1233/sc-nexus/releases). Установщик на русском, устанавливает приложение для текущего пользователя и добавляет ярлык в меню «Пуск». Ярлык рабочего стола — по выбору. .NET отдельно не нужен. Обновление и удаление приложения сохраняют `%LOCALAPPDATA%\SCNexus` с балансом, флотом и историей.

## Рейсы с остановками

В «Маршрутах» выберите режим **Цепочка** или **Сбор груза**, корабль, бюджет и до 2–5 точек закупки. Конечный терминал можно выбрать из списка (поиск по системе и названию) или оставить автоподбор. Стартовая точка и фильтры используются из той же формы.

Галочки **Системы маршрута** позволяют выбрать одну или несколько систем: все остановки будут внутри выбранного набора. Это отдельное ограничение от поиска стартовой локации. Если снять все галочки, результатов не будет. **Только рейсы внутри одной системы** дополнительно запрещает переходы между системами. Под режимом показано объяснение с примером.

- **Цепочка:** продажа всего груза на каждом участке, затем закупка следующего. Выручка доступна для следующих закупок. Терминалы не повторяются. Минимальное заполнение действует на каждый участок.
- **Сбор груза:** несколько закупок, разные товары, одна финальная разгрузка. Трюм, исходный бюджет и спрос на товар в конечной точке учитываются совместно.
- Каждый план показывает порядок остановок, покупки/продажи, свободный трюм, остаток доступных денег и Pyro. Можно сохранить план в TXT или перенести описание остановок в журнал рейса. Для фактической прибыли укажите общие закупки и продажи за все участки.

Подбор ограничен поиском выгодных вариантов: до 12 планов, без гарантии глобального оптимума. Расстояния, время и топливо не учитываются. Время котировок показано в плане; данные UEX требуют проверки в игре.

## Сборка из исходников

Требуются Windows и .NET 10 SDK. Запуск: `dotnet run --project SCNexus/SCNexus.csproj`. Сборка: `dotnet build SCNexus.slnx`.

Локальный готовый файл: `dist/SCNexus.exe`. Команда самостоятельной публикации: `dotnet publish SCNexus/SCNexus.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o dist`.

Готовый Windows-файл после каждой загрузки изменений доступен в разделе **Actions → Windows build → Artifacts** репозитория как `SCNexus-win-x64`. Для его запуска .NET SDK не нужен.

Баланс, текущий корабль, локация, резерв денег, фильтры маршрутов и путь к игре автоматически сохраняются в SQLite по пути `%LOCALAPPDATA%\SCNexus\nexus.db`. Бюджет, резерв и старт меняются прямо в **Маршрутах**. Денежные поля принимают пробелы между разрядами, запятую или точку и проверяют ввод. Корабль выбирается из личного флота. Локации подгружаются из UEX и находятся по системе и нескольким буквам названия. Кнопка **Любая локация** снимает ограничение по месту старта; результаты раскрываются порциями по 30. **Обновить цены** запрашивает свежие котировки.

Приложение загружает [котировки UEX](https://uexcorp.space/api/documentation/id/get_commodities_prices_all/) и [терминалы UEX](https://uexcorp.space/api/documentation/id/get_terminals/). Котировки кэшируются на 30 минут, терминалы — на 12 часов в `%LOCALAPPDATA%\SCNexus\cache`. При недоступности сети используется сохранённый кэш с отметкой `DATA OLD`. Для каждого маршрута показаны дата котировки, объём, закупка, расчётная прибыль и ROI.

UEX поддерживается игроками. `scu_buy` — последнее сообщённое количество для покупки, `scu_sell` — прогноз спроса. Они могут измениться до вашего приезда; проверьте терминал перед вложением денег. Личный profit/hour считается по вашим завершённым рейсам. Когда для точного сочетания товара и маршрута есть история, карточка показывает ваше среднее время.

Карточки маршрутов показывают системы отправления и назначения, заполнение трюма, запас и спрос, цены за SCU, вложения, расчётную выручку и прибыль. Любой маршрут через Pyro помечается как опасный; наличие терминала NQA отмечается отдельно.

## Флот и рейсы

В разделе **Мой флот** найдите модель в каталоге кораблей UEX и выберите её: название и грузовой объём подставятся автоматически. Каталог кэшируется на 12 часов. Роль определяется по модели корабля и при необходимости редактируется перед добавлением; при неизвестной специализации подставляется «Универсальный». Для своих кораблей можно сохранить заметки о сборке; список сортируется по названию или вместимости. Кнопка **Выбрать для рейсов** выбирает корабль для поиска маршрутов. Его заработок считается по завершённым рейсам. Удаление корабля не удаляет историю.

Выбор модели сделан выпадающим списком всех кораблей каталога. Дополнительный поиск по названию открывается отдельно; сортировка работает по названию или грузовому объёму. Можно сравнить вместимость и назначение двух моделей. Форма добавления раскрывается по нажатию.

В разделе **Маршруты** выбирается корабль из личного флота и рассчитываются рейсы по его вместимости, доступному балансу и запасу/спросу терминалов. Можно искать из выбранной стартовой точки или из всех локаций. Есть сортировка по прибыли за рейс, прибыли за SCU, марже, вложениям и заполнению трюма; фильтры по типу маршрута, межсистемным рейсам, NQA, Pyro, минимальному заполнению и минимальной прибыли. Показаны затраты, прибыль, заполнение, запас, спрос и время котировки. Выбранный маршрут можно перенести в запись рейса.

В разделе **Рейсы и история** выберите корабль из личного флота прямо перед рейсом, начните рейс вручную или перенесите маршрут из рекомендации. Список кораблей сортируется по названию или вместимости. Время начала и конца записывается автоматически. При завершении укажите фактические вложения, выручку, расходы и потери. Чистая прибыль добавится к сохранённому балансу. История и флот хранятся в той же локальной SQLite-базе.

SC NEXUS сам ищет установленную игру в типичных папках дисков Windows и каждые 15 секунд читает хвост `Game.log` вместе с недавними архивами. Найденные запросы покупки и продажи показываются в истории; их суммы можно подставить в рейс. Журнал не подтверждает успешное завершение сделки и не содержит точный остаток aUEC, поэтому баланс меняется только после ручного завершения рейса. Игровые файлы читаются локально и не отправляются на сервер.

Раздел **Инструменты** работает внутри SC NEXUS: показывает, запущена ли игра, определяет последний сервер и регион по `Game.log`, показывает последние журналы игровых сессий, проверяет журнал, свободное место, `user.cfg` и файлы локализации. Кнопка **Обновить данные** повторяет проверку, а **Выбрать Game.log** позволяет указать файл вручную, если автоопределение не сработало. Папку игры можно также указать в настройках. Учёт торговых запросов из журнала находится в разделе истории.

## Дальше

В **Настройках** можно выбрать папку LIVE/PTU/EPTU, включить или приостановить фоновое чтение журнала, задать интервал 15/30/60 секунд и скрыть подробности карточек маршрутов. Здесь же доступны резервная копия всей базы SQLite, экспорт рейсов в CSV и папка данных. Отчёт проверки ПК сохраняется из инструментов. [Разбор интерфейса и границы функций](docs/interface-audit.md).

Следующие этапы — полноценный трекер игровой сессии, быстрые операции покупки и продажи, расширенная аналитика и остальные пункты ТЗ.
