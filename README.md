# SC NEXUS

Личное Windows-приложение-компаньон для Star Citizen. В обзоре видны баланс и текущий корабль; маршруты, флот, история рейсов, инструменты и настройки открываются из верхнего меню.

## Запуск

Требуются Windows и .NET 10 SDK. Запуск: `dotnet run --project SCNexus/SCNexus.csproj`. Сборка: `dotnet build SCNexus.slnx`.

Баланс, текущий корабль, локация, резерв денег, фильтры маршрутов и путь к игре автоматически сохраняются в SQLite по пути `%LOCALAPPDATA%\SCNexus\nexus.db`. Корабль выбирается из личного флота. Локации подгружаются из UEX и находятся по системе и нескольким буквам названия. Кнопка **Все локации** снимает ограничение по месту старта; результаты в разделе маршрутов раскрываются порциями по 30.

Приложение загружает [котировки UEX](https://uexcorp.space/api/documentation/id/get_commodities_prices_all/) и [терминалы UEX](https://uexcorp.space/api/documentation/id/get_terminals/). Котировки кэшируются на 30 минут, терминалы — на 12 часов в `%LOCALAPPDATA%\SCNexus\cache`. При недоступности сети используется сохранённый кэш с отметкой `DATA OLD`. Для каждого маршрута показаны дата котировки, объём, закупка, расчётная прибыль и ROI.

UEX поддерживается игроками. `scu_buy` — последнее сообщённое количество для покупки, `scu_sell` — прогноз спроса. Они могут измениться до вашего приезда; проверьте терминал перед вложением денег. Личный profit/hour считается по вашим завершённым рейсам. Когда для точного сочетания товара и маршрута есть история, карточка показывает ваше среднее время.

Карточки маршрутов показывают системы отправления и назначения, заполнение трюма, запас и спрос, цены за SCU, вложения, расчётную выручку и прибыль. Любой маршрут через Pyro помечается как опасный; наличие терминала NQA отмечается отдельно.

## Флот и рейсы

В разделе **Мой флот** найдите модель в каталоге кораблей UEX и выберите её: название и грузовой объём подставятся автоматически. Каталог кэшируется на 12 часов. Роль определяется по модели корабля и при необходимости редактируется перед добавлением; при неизвестной специализации подставляется «Универсальный». Для своих кораблей можно сохранить заметки о сборке; список сортируется по названию или вместимости. Кнопка **Выбрать для рейсов** выбирает корабль для поиска маршрутов. Его заработок считается по завершённым рейсам. Удаление корабля не удаляет историю.

Выбор модели сделан выпадающим списком всех кораблей каталога. Внутри списка можно набрать две буквы имени, чтобы отфильтровать варианты; сортировка работает по названию или грузовому объёму.

В разделе **Маршруты** выбирается корабль из личного флота и рассчитываются рейсы по его вместимости, доступному балансу и запасу/спросу терминалов. Можно искать из выбранной стартовой точки или из всех локаций. Есть сортировка по прибыли за рейс, прибыли за SCU, марже, вложениям и заполнению трюма; фильтры по типу маршрута, межсистемным рейсам, NQA, Pyro, минимальному заполнению и минимальной прибыли. Показаны затраты, прибыль, заполнение, запас, спрос и время котировки. Выбранный маршрут можно перенести в запись рейса.

В разделе **Рейсы и история** выберите корабль из личного флота прямо перед рейсом, начните рейс вручную или перенесите маршрут из рекомендации. Список кораблей сортируется по названию или вместимости. Время начала и конца записывается автоматически. При завершении укажите фактические вложения, выручку, расходы и потери. Чистая прибыль добавится к сохранённому балансу. История и флот хранятся в той же локальной SQLite-базе.

SC NEXUS сам ищет установленную игру в типичных папках дисков Windows и каждые 15 секунд читает хвост `Game.log` вместе с недавними архивами. Найденные запросы покупки и продажи показываются в истории; их суммы можно подставить в рейс. Журнал не подтверждает успешное завершение сделки и не содержит точный остаток aUEC, поэтому баланс меняется только после ручного завершения рейса. Игровые файлы читаются локально и не отправляются на сервер.

Раздел **Инструменты** работает внутри SC NEXUS: показывает, запущена ли игра, определяет последний сервер и регион по `Game.log`, показывает последние журналы игровых сессий, проверяет журнал, свободное место, `user.cfg` и файлы локализации. Кнопка **Обновить данные** повторяет проверку, а **Выбрать Game.log** позволяет указать файл вручную, если автоопределение не сработало. Папку игры можно также указать в настройках. Учёт торговых запросов из журнала находится в разделе истории.
