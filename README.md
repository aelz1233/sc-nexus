# SC NEXUS

Личное Windows-приложение-компаньон для Star Citizen. Реализованы dashboard, боковое меню, локальные настройки и подбор торговых маршрутов по котировкам UEX.

## Запуск

Требуются Windows и .NET 10 SDK. Запуск: `dotnet run --project SCNexus/SCNexus.csproj`. Сборка: `dotnet build SCNexus.slnx`.

Баланс, текущий корабль, локация, SCU корабля, резерв денег и разрешение NQA-терминалов автоматически сохраняются в SQLite по пути `%LOCALAPPDATA%\SCNexus\nexus.db`. В настройках укажите эти параметры, затем нажмите «Что мне делать сейчас?».

Приложение загружает [котировки UEX](https://uexcorp.space/api/documentation/id/get_commodities_prices_all/) и [терминалы UEX](https://uexcorp.space/api/documentation/id/get_terminals/). Котировки кэшируются на 30 минут, терминалы — на 12 часов в `%LOCALAPPDATA%\SCNexus\cache`. При недоступности сети используется сохранённый кэш с отметкой `DATA OLD`. Для каждого маршрута показаны дата котировки, объём, закупка, расчётная прибыль и ROI.

UEX поддерживается игроками. `scu_buy` — последнее сообщённое количество для покупки, `scu_sell` — прогноз спроса. Они могут измениться до вашего приезда; проверьте терминал перед вложением денег. Время рейса и прибыль в час пока не вычисляются, потому что подтверждённых данных о времени пути нет.
