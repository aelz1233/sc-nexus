# SC NEXUS

Личное Windows-приложение-компаньон для Star Citizen. Реализован этап 1: WPF dashboard, боковое меню, локальные настройки и демонстрационные маршруты. Маршруты вымышлены и явно помечены как демо; приложение не выдаёт их за актуальные цены.

## Запуск

Требуются Windows и .NET 10 SDK. Запуск: `dotnet run --project SCNexus/SCNexus.csproj`. Сборка: `dotnet build SCNexus.slnx`.

Баланс, текущий корабль и локация автоматически сохраняются в SQLite по пути `%LOCALAPPDATA%\SCNexus\nexus.db`.
