# SC NEXUS

Личное Windows-приложение-компаньон для Star Citizen. Реализованы dashboard, локальные настройки, подбор торговых маршрутов по котировкам UEX, личный флот и история реальных рейсов.

## Запуск

Требуются Windows и .NET 10 SDK. Запуск: `dotnet run --project SCNexus/SCNexus.csproj`. Сборка: `dotnet build SCNexus.slnx`.

Баланс, текущий корабль, локация, SCU корабля, резерв денег и разрешение NQA-терминалов автоматически сохраняются в SQLite по пути `%LOCALAPPDATA%\SCNexus\nexus.db`. Корабль выбирается из личного флота; список можно сортировать по названию или вместимости. Локации подгружаются из UEX и находятся по системе и нескольким буквам названия.

Приложение загружает [котировки UEX](https://uexcorp.space/api/documentation/id/get_commodities_prices_all/) и [терминалы UEX](https://uexcorp.space/api/documentation/id/get_terminals/). Котировки кэшируются на 30 минут, терминалы — на 12 часов в `%LOCALAPPDATA%\SCNexus\cache`. При недоступности сети используется сохранённый кэш с отметкой `DATA OLD`. Для каждого маршрута показаны дата котировки, объём, закупка, расчётная прибыль и ROI.

UEX поддерживается игроками. `scu_buy` — последнее сообщённое количество для покупки, `scu_sell` — прогноз спроса. Они могут измениться до вашего приезда; проверьте терминал перед вложением денег. Личный profit/hour считается по вашим завершённым рейсам. Когда для точного сочетания товара и маршрута есть история, карточка показывает ваше среднее время.

## Флот и рейсы

В разделе **Мой флот** добавьте свои корабли с грузовым объёмом, ролью и заметками о сборке. Кнопка **Выбрать для рейсов** выбирает корабль для поиска маршрутов. Его заработок считается по завершённым рейсам. Удаление корабля не удаляет историю.

В разделе **Рейсы и история** начните рейс вручную или перенесите маршрут из рекомендации. Время начала и конца записывается автоматически. При завершении укажите фактические вложения, выручку, расходы и потери. Чистая прибыль добавится к сохранённому балансу. История и флот хранятся в той же локальной SQLite-базе.
