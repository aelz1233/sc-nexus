# SC NEXUS

Приложение для Star Citizen: помогает подобрать торговый маршрут, вести список своих кораблей и записывать результаты рейсов. Интерфейс на русском языке. Работает на Windows 10/11 (x64).

## Установка

Скачайте [последнюю версию](https://github.com/aelz1233/sc-nexus/releases/latest):

- **SCNexus-Setup-…exe** — обычная установка;
- **SCNexus-…win-x64.zip** — запуск без установки.

Во время установки можно выбрать папку для программы. Отдельно устанавливать .NET не нужно. При обновлении баланс, флот и история рейсов сохраняются в `%LOCALAPPDATA%\SCNexus`.

## Что есть в приложении

**Маршруты.** Выберите корабль, укажите бюджет и при желании стартовую точку. Приложение покажет варианты покупки и продажи груза с расчётной прибылью и заполнением трюма. Есть фильтры по системам и несколько режимов планирования: прямой рейс, цепочка продаж и сбор груза с доставкой в одну точку. Маршруты через Pyro отмечены как опасные.

**Флот.** Добавляйте корабли из каталога, сортируйте их по названию или вместимости и выбирайте корабль для рейса.

**Рейсы.** Записывайте вложения, выручку, расходы и потери. История показывает фактическую прибыль за выбранный период. Ошибочную запись можно удалить. Если найден `Game.log`, суммы торговых запросов подставляются в форму; их можно исправить вручную.

**Инструменты.** Приложение ищет установленную игру, читает `Game.log`, показывает сведения о последней сессии и проверяет некоторые локальные файлы. Историю можно экспортировать в CSV, а личную базу — сохранить в резервную копию.

**Обновление.** В настройках нажмите «Проверить обновление». Приложение скачает установщик последнего релиза, проверит его контрольную сумму и запустит после закрытия. Репозиторий закрытый, поэтому для проверки нужен личный токен GitHub с доступом `Contents: Read` к `sc-nexus`. Токен сохраняется в зашифрованном виде для текущего пользователя Windows.

## Откуда берутся цены

Котировки, терминалы и каталог кораблей загружаются из [UEX](https://uexcorp.space/). Расчётная прибыль основана на этих данных и может отличаться от результата в игре. Перед закупкой проверяйте цену, запас и спрос в терминале.

## Сборка из исходников

Нужны Windows и .NET 10 SDK:

```powershell
dotnet run --project SCNexus/SCNexus.csproj
```

```powershell
dotnet test SCNexus.slnx -c Release
```
